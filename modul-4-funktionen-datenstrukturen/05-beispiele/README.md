# Beispiele: Modul 4

Vollständige Beispielprogramme für Modul 4.

## 💻 Programme

### Einstieg in Funktionen

1. `01-begruessung.py` - Einfache Funktion ohne Parameter
2. `02-mehrere-funktionen.py` - Mehrere Funktionen kombinieren
3. `03-funktionen-in-schleifen.py` - Funktionen wiederholt aufrufen
4. `addiere.py` - Funktion mit Parametern und Rückgabewert
5. `funktionen_basis.py` - Grundlegende Funktionen
6. `parameter.py` - Parameter-Varianten

### Datenstrukturen

7. `listen_operationen.py` - Listen-Methoden
8. `dictionaries.py` - Dictionary-Operationen
9. `tupel_sets.py` - Tupel und Sets
10. `notensystem_improved.py` - Notensystem mit Datenstruktur (Listen von Tupeln, lambda)

### Anwendungen

11. `kontaktverwaltung.py` - Vollständige Kontaktverwaltung
12. `notenverwaltung.py` - Notenverwaltung mit Statistiken
13. `einkaufsliste_advanced.py` - Erweiterte Einkaufsliste
14. `woerterbuch.py` - Deutsch-Englisch Wörterbuch
15. `datenanalyse.py` - Datenanalyse mit Funktionen

### Testing

16. `testen_beispiel.py` - Testbare Funktionen (Lernbeispiel für Testing)
