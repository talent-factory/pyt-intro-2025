## 1. Was ist Programmieren?

**Programmieren** bedeutet, einem Computer **präzise Anweisungen** zu geben, um ein Problem zu lösen.

### Analogie: Kochrezept

Stellen Sie sich vor, Sie schreiben ein Kochrezept:

```text
1. Nehmen Sie 200g Mehl
2. Fügen Sie 100ml Wasser hinzu
3. Kneten Sie den Teig 5 Minuten
4. Backen Sie bei 180°C für 20 Minuten
```

Ein Programm ist ähnlich - nur für Computer:

```python
mehl = 200  # Gramm
wasser = 100  # Milliliter
temperatur = 180  # Grad Celsius
backzeit = 20  # Minuten
```

**Wichtig:** Computer sind **extrem präzise**, aber **nicht intelligent**. Sie tun **genau**, was Sie ihnen sagen - nicht mehr, nicht weniger.

## 2. Warum Python?

Python ist eine der **beliebtesten Programmiersprachen** weltweit.

### Vorteile für Anfänger

✅ **Einfache Syntax** - Liest sich fast wie Englisch  
✅ **Vielseitig** - Web, Datenanalyse, KI, Automatisierung  
✅ **Grosse Community** - Viele Hilfsressourcen  
✅ **Schnelle Ergebnisse** - Sofort sichtbare Erfolge  

### Beispiel: "Hello World"

**Python:**

```python
print("Hello, World!")
```

**Java (zum Vergleich):**

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Python ist **deutlich einfacher**!

## 3. Wie funktioniert ein Programm?

### Der Ablauf

1. **Sie schreiben Code** (in einer Datei, z.B. `programm.py`)
2. **Python liest den Code** (Zeile für Zeile)
3. **Python führt aus** (macht, was Sie geschrieben haben)
4. **Ergebnis** (wird angezeigt oder gespeichert)

### Beispiel

**Code:**

```python
name = "Anna"
alter = 25
print(f"{name} ist {alter} Jahre alt")
```

**Ablauf:**

1. Speichere "Anna" in Variable `name`
2. Speichere 25 in Variable `alter`
3. Zeige Text an: "Anna ist 25 Jahre alt"

## 4. Grundkonzepte

### Variablen

**Variablen** sind **Speicherplätze** für Daten.

```python
x = 10  # x speichert die Zahl 10
name = "Max"  # name speichert den Text "Max"
```

Wie Schubladen mit Etiketten:

- Schublade "x" enthält 10
- Schublade "name" enthält "Max"

### Datentypen

Verschiedene **Arten von Daten**:

```python
zahl = 42  # int (Ganzzahl)
preis = 19.99  # float (Dezimalzahl)
name = "Python"  # str (Text/String)
ist_wahr = True  # bool (Wahrheitswert)
```

### Operationen

**Berechnungen** und **Vergleiche**:

```python
# Mathematik
summe = 5 + 3  # 8
produkt = 4 * 2  # 8
potenz = 2 ** 3  # 8 (2 hoch 3)

# Vergleiche
ist_groesser = 10 > 5  # True
ist_gleich = 3 == 3  # True
```
