# Übung 1: Hello World

**Dauer:** 15 Minuten  
**Schwierigkeit:** ⭐ Einfach  
**Lektion:** 1 - Was ist Programmieren?

## 🎯 Lernziele

- Python Shell öffnen
- Erste Befehle ausführen
- `print()` Funktion nutzen
- Variablen erstellen

## 📝 Aufgaben

### Teil 1: Python Shell (7 Min.)

1. Öffnen Sie die Python Shell
2. Geben Sie folgende Befehle ein:

```python
>>> print("Hello, World!")
>>> print("Mein erstes Python-Programm!")
>>> print("Python macht Spass!")
```

### Teil 2: Variablen (8 Min.)

3. Erstellen Sie Variablen:

```python
>>> name = "Ihr Name"
>>> alter = 25  # Ihr Alter
>>> stadt = "Ihre Stadt"
```

4. Geben Sie die Variablen aus:

```python
>>> print(name)
>>> print(alter)
>>> print(stadt)
```

5. Kombinieren Sie:

```python
>>> print(f"Ich bin {name}, {alter} Jahre alt und wohne in {stadt}")
```

## ✅ Erfolgskriterien

- [ ] Python Shell geöffnet
- [ ] Texte ausgegeben
- [ ] Variablen erstellt
- [ ] Variablen ausgegeben
- [ ] F-String verwendet

## 🚀 Erweiterungen

Wenn Sie fertig sind:

- Geben Sie verschiedene Texte aus
- Erstellen Sie mehr Variablen (Hobby, Lieblingsfarbe, etc.)

## 💡 Hilfe

**Problem:** Python Shell öffnet nicht  
**Lösung:** Terminal öffnen, `python` oder `python3` eingeben

**Problem:** Fehler bei `print()`
**Lösung:** Klammern und Anführungszeichen prüfen
