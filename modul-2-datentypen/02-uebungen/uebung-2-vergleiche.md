# Übung 2: Vergleiche und logische Operatoren

**Dauer:** 15 Minuten  
**Schwierigkeit:** ⭐ Einfach

## 🎯 Lernziel

Vergleichsoperatoren und logische Operatoren anwenden

## 📝 Aufgabe

Erstellen Sie ein Programm `vergleiche.py`, das:

1. Variablen für Alter, Temperatur und Name definiert
2. Verschiedene Vergleiche durchführt
3. Logische Operatoren verwendet
4. Die Ergebnisse ausgibt

## 💡 Beispiel-Ausgabe

```
=== Vergleiche ===

Alter: 20
Temperatur: 25°C
Name: Max

Einzelne Prüfungen:
- Volljährig (>= 18): True
- Warm (> 20): True
- Name ist 'Max': True
- Name ist 'Anna': False

Kombinierte Prüfungen:
- Volljährig UND warm: True
- Volljährig ODER warm: True
- NICHT volljährig: False
```

## 🔧 Hilfestellung

Operatoren:
- Vergleiche: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Logisch: `and`, `or`, `not`

## ✅ Checkliste

- [ ] Variablen definiert
- [ ] Vergleiche durchgeführt
- [ ] Logische Operatoren verwendet
- [ ] Ergebnisse ausgegeben
