# Übung 8: Textanalyse

**Dauer:** 15 Minuten  
**Schwierigkeit:** ⭐⭐⭐ Schwer  
**Status:** Vertiefung (zu Hause)

## 📝 Aufgabe

Erstellen Sie `textanalyse_uebung.py`:

- Eingabe: Mehrzeiliger Text
- Analysiere: Zeichen, Wörter, Sätze
- Zeige Statistik

## 💡 Beispiel

```
Text: Hallo Welt. Dies ist ein Test.

Statistik:
- Zeichen: 31
- Wörter: 6
- Sätze: 2
- Durchschnitt: 3.0 Wörter/Satz
```

## ✅ Checkliste

- [ ] Zeichen gezählt
- [ ] Wörter gezählt
- [ ] Sätze gezählt
- [ ] Durchschnitt berechnet
