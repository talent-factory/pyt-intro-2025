# Übung 5: String-Methoden

**Dauer:** 15 Minuten  
**Schwierigkeit:** ⭐⭐ Mittel  
**Status:** Vertiefung (zu Hause)

## 📝 Aufgabe

Erstellen Sie `string_methoden.py`:

- Eingabe: Ein Text
- Wende verschiedene String-Methoden an
- Zeige Ergebnisse

## 💡 Beispiel

```
Text: Hallo Welt

Gross: HALLO WELT
Klein: hallo welt
Titel: Hallo Welt
Länge: 10 Zeichen
Anzahl 'l': 3
Ersetzt: Hollo Welt
Wörter: ['Hallo', 'Welt']
```
