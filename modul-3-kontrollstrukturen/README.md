# Modul 3: Kontrollstrukturen

**Dauer:** 1 Tag (4 Lektionen à 50 Minuten)
**Voraussetzung:** Modul 1 & 2 abgeschlossen

## 🎯 Lernziele

Nach diesem Modul können Sie:

1. ✅ Bedingte Anweisungen (if, elif, else) für Entscheidungen nutzen
2. ✅ While-Schleifen für wiederholte Ausführung verwenden
3. ✅ For-Schleifen für Iteration über Sequenzen einsetzen
4. ✅ Verschachtelte Kontrollstrukturen verstehen und anwenden
5. ✅ Break und continue für Schleifensteuerung nutzen
6. ✅ Listen erstellen, manipulieren und durchlaufen
7. ✅ Komplexe Programme mit mehreren Kontrollstrukturen entwickeln
8. ✅ Häufige Fehler bei Schleifen erkennen und vermeiden

## 📖 Themen im Detail

### Bedingte Anweisungen
- If/elif/else Strukturen
- Vergleichsoperatoren in Bedingungen
- Logische Operatoren (and, or, not)
- Verschachtelte Bedingungen
- Ternärer Operator

### While-Schleifen
- While-Syntax und Funktionsweise
- Schleifenbedingungen
- Break und continue
- Endlosschleifen vermeiden
- Zähler und Akkumulatoren

### For-Schleifen & Listen
- For-Loops über Listen
- Range-Funktion
- Enumerate und Zip
- List Comprehensions (Einführung)
- Iteration über Strings

### Verschachtelte Strukturen
- Schleifen in Schleifen
- Bedingungen in Schleifen
- Komplexe Algorithmen
- Muster und Pyramiden
- Debugging verschachtelter Code

### Projekt
- Zahlenraten-Spiel
- Einkaufsliste
- Primzahlen-Finder
- Menü-gesteuerte Anwendungen
