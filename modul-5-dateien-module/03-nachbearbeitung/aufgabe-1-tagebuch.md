# Aufgabe 1: Tagebuch-App


Erstellen Sie eine vollständige Tagebuch-Anwendung.

**Anforderungen:**

1. Einträge in Textdatei speichern
2. Funktionen:
   - `neuer_eintrag()` - Fügt Eintrag mit Datum/Zeit hinzu
   - `eintraege_anzeigen()` - Zeigt alle Einträge
   - `suche(suchbegriff)` - Sucht in Einträgen
   - `export_json()` - Exportiert nach JSON

**Beispiel-Ausgabe:**
```
TAGEBUCH
========
[2025-01-15 14:30] Heute war ein guter Tag!
[2025-01-16 09:15] Python macht Spass!
```

**Zeitaufwand:** 2 Stunden

**Erweiterungen:**
- Kategorien/Tags
- Stimmung (😊 😐 😢)
- Statistiken (Einträge pro Monat)
